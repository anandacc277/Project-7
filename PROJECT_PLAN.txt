────────────────────────────────────────────────────────────────────────────
  ✓ Created: .github/workflows/terraform-validate.yml
    
    Triggers:
    • On: push to main/develop branches
    • On: pull request to main/develop
    • Filtered by: *.tf and *.tfvars files

    Validation Steps:
    1. Checkout code (actions/checkout@v4)
    2. Setup Terraform (v1.6.0)
    3. Terraform format check (terraform fmt -check -recursive)
    4. Terraform validate (terraform init && terraform validate)
    5. Post PR comments with results
    6. Fail on format issues

    Features:
    • Runs on every push/PR
    • Posts helpful comments on PRs
    • Proper error handling
    • Fast feedback (~2-3 minutes)
